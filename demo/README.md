# Demo seeds

`seeds.jsonl`: 20 merchant-support tickets (BG, EN and mixed). 15 have `"holdout": false` and go
verbatim into the frozen eval set (`source: "seed"`); 5 have `"holdout": true` and are used only in
the playground, never in any dataset file.

Authorship, stated plainly: these seeds were written by Claude (the coding agent) on 2026-10-13 at
the project owner's request, not by a human. They follow the labeling guidelines in
`app/app/Support/TaskTemplate.php` (urgency high = money lost, missed deadline or a threat to leave;
needs_human = refunds, complaints, legal). The rest of the eval set is synthetic, generated by
Qwen3.8-27B from these seeds.
